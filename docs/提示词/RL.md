# 背景说明（不画进图，供理解用）

- 迷宫这个例子里，状态就是「现在站在哪个格子」，动作就是「上下左右走一格」，奖励是「走到终点给 1，其余给 0」。策略是一个从格子到方向的表。走错就退回来重走，试够多次就知道怎么走最快。
- 换成大模型，四个词一一对上：状态是已生成的前缀，动作是下一个 token，奖励是判分函数给的 0 或 1，策略就是模型本身。
- 真正不同的地方只有两处：一是动作空间，迷宫只有 4 个方向，模型要在整个词表上选；二是奖励的来源，迷宫的奖励写在游戏规则里，模型的奖励得我们自己写一个判分函数算出来。
- 还有一处正文里会讲、图上不强调：模型生成完一条回答才开始判分，中间任何一个 token 都没有分。
- 一组回答内部比较，是为了解决「奖励只有 0 和 1，同一道题如果全对或全错就没有梯度」的问题：减去组内均值后，高于平均的被推高、低于平均的被压低。
